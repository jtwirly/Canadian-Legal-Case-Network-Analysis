Each dossier below is built from full-text keyword detection across the corpus, manually checked against surrounding context to drop false hits (citation-list mentions, idiomatic uses). Status is a read of case volume, recency, and how uniform the Court's answers have been — not a formal doctrinal ruling.

Method. Full text of 10,867 SCC decisions was scanned for term clusters tied to each issue; every match shown here was read in context to exclude citation-list noise. This corpus is Supreme Court of Canada judgments only — it does not include lower-court decisions, legislation, regulatory rulings, or academic literature, so an issue can be very live in those other channels while still showing thin here because it hasn't reached the country's top court yet. Counts reflect keyword presence, not holdings; read "unsettled" as a volume-and-recency signal worth a closer look, not a legal conclusion.
